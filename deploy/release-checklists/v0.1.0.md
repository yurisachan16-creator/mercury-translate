# Mercury Translate v0.1.0 Release Checklist

## Preconditions

- [ ] Bootstrap PR has merged into `main`.
- [ ] GitHub branch rules require PRs, fresh required checks, resolved conversations, no force pushes, and no branch deletion.
- [ ] GitHub tag rules protect `v*` tags from updates and deletion.
- [ ] Repository settings enable Issues, disable Wiki and Projects, enable automatic deletion of merged branches, allow squash and rebase merge, and disable merge commits.

## Local Verification

- [ ] `pnpm compile`
- [ ] `pnpm test`
- [ ] `pnpm build`
- [ ] `pnpm docs:build`
- [ ] `pnpm zip`
- [ ] `git diff --check`
- [ ] `unzip -t .output/mercury-translate-0.1.0-chrome.zip`
- [ ] SHA-256 recorded for `.output/mercury-translate-0.1.0-chrome.zip`

## Release Verification

- [ ] Annotated tag is exactly `v0.1.0`, matching `package.json`.
- [ ] Release job uploaded the Chrome ZIP, source archive, `SHA256SUMS`, `LICENSE`, `NOTICE`, `INSTALL.md`, `THIRD_PARTY_NOTICES.md`, and OCR language packs for `eng`, `chi_sim`, `chi_tra`, `jpn`, and `kor`.
- [ ] Downloaded release ZIP SHA-256 matches `SHA256SUMS`.
- [ ] Clean Chrome 151+ profile can side-load the ZIP output and verify webpage translation, YouTube subtitles, PDF text translation, and OCR model download.
