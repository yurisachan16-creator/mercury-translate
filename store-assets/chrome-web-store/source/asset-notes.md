# Mercury store asset sources

The tracked PNG files in `store-assets/chrome-web-store/` are generated from:

- `source/icon-128.svg` for `icon-128.png`;
- `source/render.html` and `source/listing.css` for `small-promo-tile.png` and the five screenshots;
- `store-assets/scripts/generate-chrome-web-store-assets.mjs` for the asset name, size, and output map.

No remote images, paid services, generated brand identity, Chrome Web Store item ID, or third-party marketplace screenshots are used.
