# 关于 Mercury Translate

Mercury Translate（水星翻译）是一个本地优先、无账号、无自建中转服务器、无订阅、无付款功能和无遥测的
GPL-3.0 浏览器扩展。v0.1 面向 Chrome 桌面版 151 或更高版本，并通过 GitHub Release 及准备中的不公开搜索商店包发布。

主要新增和调整包括：Mercury 品牌与三语界面、Chrome 本地翻译优先的隐私边界、联网服务明确授权、
PDF 双栏阅读器、OpenAI 兼容 / Sub2API 配置流程，以及经过固定版本和 SHA-256 校验的 OCR 模型管线。
