# 关于 Mercury Translate

Mercury Translate（水星翻译）是一个本地优先、无账号、无自建中转服务器、无订阅和无遥测的
GPL-3.0 浏览器扩展。v0.1 面向 Chrome 桌面版 151 或更高版本，并通过 GitHub Release 发布。

本项目是 [FluentRead](https://github.com/FluentRead/FluentRead) 的独立、非官方 fork，最初基于固定提交
`f91543c6b6b76f3c5d6343b47a82e431acfa648a`。Mercury Translate 未获得 FluentRead 维护者背书，
也不代表 FluentRead 官方。我们保留 GPL-3.0、上游版权说明和第三方许可证。

主要新增和调整包括：Mercury 品牌与三语界面、Chrome 本地翻译优先的隐私边界、联网服务明确授权、
PDF 双栏阅读器，以及经过固定版本和 SHA-256 校验的 OCR 模型管线。

许可证与依赖说明见仓库根目录的 `LICENSE` 和 `THIRD_PARTY_NOTICES.md`，版本变化见 `CHANGELOG.md`。
