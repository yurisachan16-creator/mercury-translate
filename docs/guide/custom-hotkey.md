# 自定义快捷键

Mercury Translate 的快捷键由浏览器扩展管理页统一配置。这样可以避开网页自身的快捷键，也能在不打开弹窗的情况下快速执行常用操作。

## 配置步骤

### Chrome 151+

1. 打开扩展快捷键页：`chrome://extensions/shortcuts`。
2. 找到 Mercury Translate。
3. 为需要的操作点击输入框并按下新的组合键。
4. 关闭页面后，在普通网页中测试。

Mercury Translate v0.1 仅验收 Chrome 桌面版 151 及更高版本；Firefox、Safari 与其他浏览器不属于本版本支持范围。

## 建议的组合键

选择不容易与网页冲突的组合，例如 `Ctrl/Cmd + Shift + L`。不要覆盖浏览器标签页、开发者工具、输入法或操作系统已经使用的快捷键。

## 快捷键不生效

- 检查组合键是否已经被浏览器或其他扩展占用。
- 确认当前标签页不是浏览器内部页面或扩展商店页面。
- 先用弹窗按钮验证 Mercury Translate 本身是否正常。
- 修改快捷键后重新加载当前网页，再测试一次。

快捷键只负责触发操作，不会绕过网页权限限制，也不会自动修复翻译服务配置问题。
