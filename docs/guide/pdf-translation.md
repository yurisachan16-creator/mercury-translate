# PDF 双语阅读

Mercury Translate 在 Chrome 151 及更高版本中接管 `application/pdf` 文档，并在不改变原始地址的情况下打开双栏阅读器。

## 界面

- 左侧是 PDF.js 渲染的原始页面；
- 右侧按页显示对应译文块；
- 滚动任意一侧会同步对应页，点击译文可定位原文区域；
- 工具栏可以选择语言、翻译服务和 OCR 语言，也可取消、重试或清除 PDF 译文缓存。

阅读器优先处理当前可见页及前后一页，不会因为打开一份长文档就立即翻译或 OCR 整本文件。

## 文本 PDF

阅读器从 PDF 文本层获取字符与坐标，再按行、段落和页面顺序归并。表格、数学公式和图片仍以左侧原页为准；右侧译文不尝试完整复制原始排版。

## 扫描 PDF

一页可提取的非空白字符少于 20 个时，它会被标记为可能的扫描页。首次遇到时，请选择英文、简体中文、繁体中文、日文或韩文 OCR 模型。模型经 SHA-256 验证并缓存后，页面像素会在本机交给 Tesseract.js 识别。

## 隐私和缓存

PDF 原始字节只在当前阅读器的内存中保留。PDF 译文缓存使用文档指纹和文本哈希作为键，默认最长 7 天、上限 50 MB。使用联网翻译服务时，右侧待翻译文本会发送给所选服务；本地服务不可用时不会静默改用网络。

## 无法打开

密码保护、损坏或 PDF.js 不支持的文件会回退到 Chrome 原生 PDF 阅读器。首版不支持导出“已翻译 PDF”。
