# Mercury Translate（水星翻译）

### 本地优先的网页、字幕、图片与 PDF 双语阅读扩展

</div>

Mercury Translate v0.1 以 Chrome 本地 Translator API 为默认服务，支持网页双语对照、划词翻译、YouTube 双语字幕、本地 OCR 和 PDF 左右对照阅读。项目无账号、无自建中转服务器、无订阅和遥测。

- 仅支持 Chrome 桌面版 151+；
- Microsoft/Bing 和 Google 是需要明确同意的联网服务；
- DeepSeek、Gemini、OpenAI 及自定义端点由用户自带密钥；
- OCR 模型按需下载，校验 SHA-256 后在本地识别；
- PDF 原始字节仅保留在阅读器内存中。

安装、开发、隐私边界和上游归属说明请查看[主 README](../README.md)、[INSTALL](../INSTALL.md)和[隐私说明](../docs/guide/privacy-policy.md)。
